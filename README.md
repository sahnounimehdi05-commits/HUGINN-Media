# HUGINN Daily Brief — site

- `site/` : le site publié par Netlify (https://huginn-media.netlify.app).
- `scripts/publish_edition.py` : ajoute une édition (PDF, couverture, page d’accueil).

Exemple : `python3 scripts/publish_edition.py --pdf HUGINN_DAILY_BRIEF_2026-11-27.pdf --title "…" --refs 35`
